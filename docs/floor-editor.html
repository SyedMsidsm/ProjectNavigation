Build a floor map

Start with a measured sketch. Add doors and junctions, then connect adjacent locations with corridor segments. Coordinates and lengths are in metres; positive Y is your chosen building north. This editor stays in your browser. Export the floor file and import it through RAIN’s Floor maps screen.

Add a location

Use a junction where three or more corridors meet. Split a corridor at each door. Delete and re-add a location to correct it.

Connect locations

Bearings increase clockwise: north 0°, east 90°, south 180°, west 270°. Coordinate geometry is a suggestion; confirm the actual walking distance. Stairs are recorded but this version does not provide a step-free routing guarantee.
